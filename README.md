## 📝 Abstract
This repository provides raw data and executable MATLAB code for the manuscript  
**“Solid-State Optical Magnetometer: A Next-Generation Approach to Sub-Nanotesla Magnetic Sensing.”**  

The dataset includes absorption spectra obtained from a metasurface cavity composed of gold and black phosphorus under different applied currents (50 µA, 100 µA, and 200 µA), illuminated by s- and p-polarized light. The data demonstrate how Lorentz-force-induced displacements and linear dichroism enable high-sensitivity magnetic field detection.  

Data are provided as Excel files, while accompanying MATLAB scripts (.m) allow reproduction of figures and analysis.  

---

## 📊 Data Organization
- **Folder 50 µA** – Absorption spectra for applied current of 50 µA  
- **Folder 100 µA** – Absorption spectra for applied current of 100 µA  
- **Folder 200 µA** – Absorption spectra for applied current of 200 µA  
- Each folder contains:  
  - Excel raw data  
  - MATLAB analysis scripts for figure generation and spectral analysis
